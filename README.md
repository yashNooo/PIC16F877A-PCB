# PIC16F877A Development Board

A custom-designed PCB based on the **PIC16F877A microcontroller**, developed using EasyEDA Pro.

This project contains the PCB design files, schematic/project files, project board images, and manufacturing outputs required to fabricate and inspect the board.

## Project Overview

The PIC16F877A is an 8-bit microcontroller from Microchip, commonly used in embedded systems and electronics learning.

This project focuses on designing a custom development board around the PIC16F877A, providing a dedicated PCB layout for microcontroller-based experiments and embedded system development.

## CAD Software: EasyEDA

## Project Files

 `Gerber_PCB1.zip`  PCB manufacturing files 
 
 `BOM_Board1_PCB1.csv`  Bill of Materials 
 
 `PickAndPlace_PCB1.csv`  Component placement coordinates 
 
 `PIC16F877A_DEV_BOARD.epru`  EasyEDA project/design file 
 
 `project2.json`  Project data 
 
 `IMAGE/`  PCB design images 

## PCB Manufacturing

The repository includes the manufacturing files required for PCB fabrication:

- Gerber files for PCB layer manufacturing.
- BOM for component identification.
- Pick and Place file for component placement.
